# 05｜実装順・受入条件・運用

## 1. 実装順
### M0：動くUIと契約の固定
構築対象：ホーム、職種ハブ、検索、詳細の2表示モード、保存、比較、訂正・削除、source管理demo。架空fixtureで動かす。デザインだけの静止画で終わらせない。
完了：URLの状態、戻る、検索、保存、比較、空状態、エラー状態、375/1440pxを確認。デモと本番の区分が分かる。

### M1：DB・検索・worker
Repositoryを実DBへ変更。source registry、policy判定、HTML/JSON-LD抽出、原稿矛盾、source listing/cluster、更新・終了、公開projection、削除伝播をfixtureで検証。
完了：サンプル入力→抽出→管理確認→サイト内検索→外部遷移まで通る。1回目と再実行で重複が増えない。実ソースを動かさなくてもここまで進める。

### M2：小規模な実データ検証と公開
実サイトの取得scope、規約/robots、運営者表示、削除フォーム、ログ・バックアップ・エラー通知を設定。sourceごとに小さく有効化。UIを作る指示だけで本番へ公開しない。
完了：原稿の事実照合、停止伝播、stale除外、問い合わせ対応、利用/送客の測定を実環境で確認。規約やプライバシー文書のプレースホルダーを残さない。

### M3：広告の有料検証
企業/代理店の権限確認、合意書、CPC、予算、sandbox台帳、PR表示、請求レポート、無効クリック対応。
完了：広告主の明示合意、課金の再現性、予算上限、不正除外、請求の照合。最初から検索全体を有料化しない。

## 3. パフォーマンス目標（設計目標、実測ではない）
- MVPの検索：10万件の架空・正規化求人で、検索API p95 800ms以下を目標。テスト環境・同時接続数を報告する。
- 検索入力はdebounce、キャンセル可能。indexの全件をブラウザに送らない。
- LCP等のWeb指標は本番の実測と開発環境の計測を区別。
- 画像を必須としない、フォントの外部読み込みを最小にする、初回JSを削減する。

## 4. ソースの拡大判定
一度に全国全件へ拡大せず、sourceごとに以下を見る。
1. 最初の30件を原ページと照合し、企業・勤務地・給与単位・必須資格の重大誤り0を確認。
2. その後の仮指標は必須条件抽出精度98%以上、終了/変更検知の運用が成立、取得先へ負荷・拒否の兆候がないこと。
3. 小さなサンプルで誤り0でも完全な正確性の証明とはしない。サンプル数と検査日を記録。
4. 既存在庫の再確認を維持できる範囲で新規件数を増やす。

## 5. 運用ダッシュボード
source別：発見URL、有効固有募集、公開件数、取得成功/停止/stale、規約/robots確認日、残った更新能力、抽出の単価。
職種別：訪問、検索実行、0件率、比較利用、保存、外部クリック、再訪。再訪の測定方法と保存期間はプライバシー設計に従う。
広告別：gross clicks、billable、excluded、CPC、消化額、残額、再出稿。外部応募連携なしの段階は応募率欄を未計測とする。

## 6. コスト管理
金額はまだ見積もっていない。必ず費用上限を設定する対象は、外部検索API、ブラウザworker、LLM抽出、検索index、保存容量、広告テスト。

原稿変化なしではAI再抽出しない。文書全体ではなく必要部分を渡す。失敗ループの無限再試行を禁止。source当たりの取得・AI・保存原価を測定し、使われない在庫を無制限に維持しない。

## 7. 本番公開チェック
- 正式な運営法人名/住所/電話/連絡先が入力済み。
- 求人提供の届出等の要否を現在の機能で確認済み。会員化/求人通知等を後で追加するときに再確認。[S07]
- source reviewと表示範囲を記録。転載条件に応じた出典・運営者表記を実装。
- 利用規約・プライバシー・苦情/訂正・収集説明を実態に合わせ確定。
- 公式提携を受けていない相手を「提携企業」「認定データ」と表示していない。
- 管理画面の認証、バックアップ、エラー通知、復元テスト、秘密情報の管理。
- 請求が有効なら契約/単価/予算/税/停止/無効クリックの説明を確定。
- デモ求人、仮電話番号、テスト広告、公開前の商標が本番に混ざっていない。

## 8. 最後にClaude Codeが報告すること
完了したM番号、変更ファイル、起動手順、実行したコマンドと結果、画面検証サイズ、実データを使った範囲、未実施、公開前の外部設定。ビルドが通っただけで「本番運用可能」「法的問題なし」と表現しない。
