# WORKLENS｜Claude Code 実装パッケージ

作成日：2026-09-29（日本時間）／版：1.0
WORKLENS は開発用の仮称です。商標・ドメインの利用可否は未調査です。

## 何を作るか
全国・全職種へ拡張できる求人検索サービス。共通の求人データ基盤の上に、職種ごとの検索条件・比較画面を載せます。Mimipoの既存事業や顧客基盤は前提にしません。年商100億円を長期の事業目標として仮置きし、まず公開求人で利用・外部送客の実績を作り、その後クリック課金広告を導入します。売上達成や収益性を保証する計画ではありません。

## 使い方
1. ZIPを展開し、このフォルダをClaude Codeで開くか、対象リポジトリ内にコピーします。既存のCLAUDE.mdがある場合は上書きせず、本パッケージの内容を必要な範囲で統合してください。
2. START_HERE.md の「最初に渡す指示」を貼り付けます。
3. 最初の作業は M0：架空データで動く画面の完成です。実求人の公開・課金・本番デプロイは別の段階で実施します。
4. prototype/index.html をブラウザで開くと、画面の方向性と検索・保存・比較・詳細の簡易操作を確認できます。これは静的な確認用で、本番システムではありません。

## ファイル構成
- CLAUDE.md：毎回守る短い実装ルール。
- START_HERE.md：Claude Codeに渡す実行指示。M0から順に実装。
- docs/01_PRODUCT.md：コンセプト、成長仮説、範囲、収益化。
- docs/02_DATA_ACQUISITION.md：提携前の収集方針、ソース分類、表示範囲、停止ルール。
- docs/03_UX_SCREEN_SPEC.md：デザイン、画面、URL、入力・状態・文言。
- docs/04_ARCHITECTURE.md：構成、データモデル、API、収集・抽出・更新処理。
- docs/05_DELIVERY_ACCEPTANCE.md：実装順、受入テスト、公開条件、測定項目。
- docs/06_SOURCES_DECISIONS.md：確認した一次資料と、提案・未確認事項の区分。
- config/：職種定義、デザイントークン、収集元レジストリの初期例。
- contracts/domain.ts：実装の出発点となる型契約。単独の完成アプリではありません。
- fixtures/：全て架空の画面・抽出テスト用データ。本番掲載禁止。
- prototype/index.html：外部通信をしない画面プロトタイプ。
- IMPLEMENTATION_BRIEF.md：仕様をひとつにまとめた全文版。
- OVERVIEW.docx：人が読むための概要。実装の正本は各Markdownです。

## 重要な区分
「提携しない」「公開ページから取得する」「全文を再掲載できる」「有料広告として扱える」は別々です。本パッケージは、許諾が明示されない公開情報も個別の範囲確認のうえで事実情報の検索インデックスにする方式を検討対象に含めています。一方、出典表示・AI書き換え・削除窓口だけで適法になるとは扱いません。

## 実装前に決めていない項目の扱い
正式ブランド、ドメイン、運営者の公開連絡先、クラウドアカウント、実ソースの有効化、広告契約・料金は未決です。Claude Codeは架空値で公開せず、開発用プレースホルダーとfeature flagで前進してください。実装手順を止めて長い質問一覧を返す必要はありません。

## この納品の実施範囲
仕様、設定例、型契約、架空データ、静的プロトタイプまで。本番クローラーの稼働、実求人の収集・公開、規約に関する個別法律意見、Google求人枠への掲載確認、広告主の獲得は実施していません。

## 確認結果と補足
`VALIDATION.md`に、今回実施した静的UIの確認と、未実施の本番機能を明記しています。`prototype/README.md`には画面デモと本番仕様の差分、`docs/DECISIONS_LOG.md`には実装中の判断ログを用意しています。
