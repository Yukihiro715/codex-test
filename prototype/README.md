# 画面プロトタイプの確認

`index.html`を通常のブラウザで開いてください。外部のライブラリ、Webフォント、実求人APIには接続しません。求人・会社・給与は24件すべて架空で、実際の応募・送客・広告請求はしません。

## 操作できること
ホームからの職種選択、キーワードと勤務地の検索、職種別条件、給与単位と下限の絞り込み、検索条件のクリア、保存、最大3件の比較、違いのみの比較、求人詳細、訂正・削除申請の画面例、収集元管理の画面例。

## 本番仕様との差分
- 本ファイルは単一HTMLで画面状態を切り替えます。本番のルート、URLへの条件保持、ブラウザの戻る操作は`docs/03_UX_SCREEN_SPEC.md`に従って実装してください。
- スマートフォンのフィルターは簡易的な展開方式です。本番は仕様書のボトムシートとフォーカス管理を実装してください。
- 管理画面の操作、申請、元サイトへの移動はデモです。DBやキューに接続していません。
- 保存はブラウザのlocalStorageを使い、利用できない環境ではメモリ内状態にフォールバックします。今回の検証では同一セッション内の保存操作を確認し、再読み込み後の永続化は未検証です。
- 表示件数、おすすめ順、最終確認日時は架空データ用です。実績や有料順位ではありません。
- 本番の管理画面に必要な認証、権限、監査ログはまだありません。
- `fixtures/jobs.demo.json`は画面デモ向けの簡略形です。`contracts/domain.ts`の本番用ドメインモデルへの変換層を作り、両方を同じ形と誤認しないでください。

見た目はこのHTML、挙動・データ・公開条件の正本はdocsです。プロトタイプの簡略化を本番要件より優先しないでください。
